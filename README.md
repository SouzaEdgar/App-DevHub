# DevHub - #7DaysOfCode

Aplicativo Android desenvolvido em Kotlin utilizando Jetpack Compose para consumir a API do GitHub e apresentar informações de perfil e repositórios de usuários.

## Funcionalidades

* Busca de perfil do GitHub
* Exibição de:

  * Avatar
  * Nome
  * Login
  * Bio
  * Lista de repositórios
* Renderização dinâmica da lista de repositórios com LazyColumn

---

## Tecnologias utilizadas

* Kotlin
* Jetpack Compose
* Material 3
* Retrofit
* Coroutines
* Coil
* State Management com `mutableStateOf`
* LazyColumn / Lazy Lists
* Android Studio

---

## Conceitos praticados

* Consumo de API REST
* UI declarativa com Compose
* State hoisting
* Recomposição
* Mapper / Conversão de Models
* Tratamento de nullable (`String?`)
* Arquitetura em camadas
* Side Effects com `LaunchedEffect`
* Organização de projeto por responsabilidade
